Guide to important CiC scripts

CountsinCylinders.py
    Python script with functions to compute counts in cylinders
ComputeCiC.ipynb
    Python notebook where I compute CiC on SV3 catalogs, mock catalogs, etc. Saves tables of CiC to disk.
PlotCiC2.ipynb
    Notebook where I plot univariate, bivariate CiC distributions, make CiC comparisons. Reads in CiC catalogs generated by
    ComputeCiC. Generates most of the main figures for the CiC paper.
CiCMoments.py
    Python script with methods for computing moments of counts in cylinders distribution
ComputeCiCMoments.py
    Notebook where I calculate moments of the CiC distributions for SV3, mock catalogs, etc. Read in CiC catalogs generated by 
    ComputeCiC. Prints out LaTeX tables of moments.
